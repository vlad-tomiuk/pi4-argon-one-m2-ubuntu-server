# pi-server

Домашній сервер на **Raspberry Pi 4** з SSD у корпусі **Argon ONE M.2**: Ubuntu Server 24.04 LTS,
захист із коробки, Docker, мережевий диск, менеджер паролів і власні команди для швидкого огляду
стану.

Встановлення — одна команда. Далі сервер сам оновлюється, сам перезавантажується після зависання
і сам піднімає сервіси після зникнення світла.

```bash
curl -fsSL https://raw.githubusercontent.com/vlad-tomiuk/pi4-argon-one-m2-ubuntu-server/main/install.sh -o install.sh
sudo bash install.sh
```

Повний опис: [docs/installation.md](docs/installation.md)

## Ідея

На роутері не відкривається **жоден порт**. Сервер виходить назовні сам: публічні сайти — через
Cloudflare Tunnel, приватні сервіси — через Tailscale.

```
                     ┌─────────────────── СЕРВЕР ───────────────────┐
                     │                                              │
                     │   Публічні сайти          Приватні сервіси   │
                     │   • портфоліо             • менеджер паролів │
                     │   • інші проєкти          • мережевий диск   │
                     │                           • закладки         │
                     └──────────▲────────────────────────▲──────────┘
                                │                        │
                       вхідний HTTPS              зашифроване P2P
                                │                        │
                      ┌─────────┴────────┐     ┌─────────┴────────┐
                      │ Cloudflare Tunnel│     │    Tailscale     │
                      └─────────▲────────┘     └─────────▲────────┘
                                │                        │
                        інтернет, будь-хто      лише твої пристрої
```

## Що ти отримуєш

| | |
|---|---|
| **Система** | Ubuntu Server 24.04 LTS (arm64) на M.2 SATA SSD, завантаження з USB |
| **Захист** | UFW, fail2ban, жорсткий SSH, автооновлення безпеки, захист мережі на рівні ядра |
| **Автовідновлення** | апаратний watchdog, reboot при kernel panic, авто-fsck, постійний журнал |
| **Docker** | Docker + Compose, папка `/srv/apps` під сервіси |
| **Мережевий диск** | SMB-диск фіксованого розміру, підключається у Windows як буква |
| **Менеджер паролів** | Vaultwarden за Tailscale, з бекапами на окрему microSD |
| **Закладки** | Linkwarden: колекції, теги, архівування сторінок, за Tailscale |
| **Вентилятор Argon** | офіційний драйвер + власний запасний, якщо офіційний не працює |
| **Команди** | `server-status`, `disk-status`, `password-status`, `bookmarks-status`, `server-update` |
| **Утиліти** | `htop`, `mc`, `tree`, `sqlite3` — ставляться одразу |

## Структура

```
install.sh              прошивка SSD + налаштування першого старту
bin/                    команди, які стають /usr/local/bin/*
  lib/ui.sh             спільне оформлення звітів
scripts/
  firstboot.sh          усе, що виконується при першому старті сервера
  install-commands.sh   bin/* → /usr/local/bin
  setup-share.sh        мережевий диск
  setup-backup-sd.sh    microSD під бекапи
systemd/                юніти (запасний драйвер вентилятора)
apps/                   сервіси, кожен окремим docker-compose проєктом
  vaultwarden/          менеджер паролів
  linkwarden/           закладки
windows/                скрипти для клієнтського ПК
docs/                   документація
```

`install.sh` робить мінімум: стирає SSD, записує Ubuntu і ставить сервіс, який при першому старті
клонує цей репозиторій у `/opt/pi-server` і виконує `scripts/firstboot.sh`. Тому налаштування
можна правити без переустановлення системи:

```bash
server-update --self     # git pull + перевстановлення команд
```

## Після встановлення

```bash
ssh ТВІЙ_ЮЗЕР@server.local
server-status

sudo bash /opt/pi-server/scripts/setup-share.sh       # мережевий диск
sudo bash /opt/pi-server/scripts/setup-backup-sd.sh   # бекапи на microSD
```

Менеджер паролів — [docs/passwords.md](docs/passwords.md). Далі додаєш свої сервіси в `/srv/apps`.

## Форк під себе

Репозиторій задуманий як основа, яку форкають:

1. форкни і зміни під себе `bin/`, `apps/`, `scripts/`;
2. встановлюй із власного репозиторію:

```bash
sudo bash install.sh --repo https://github.com/ти/твій-форк.git
```

Сервер клонує саме його, тож твої команди й сервіси приїдуть одразу при встановленні.

## Обмеження

- Перевірено на Raspberry Pi 4 з Argon ONE M.2. Інші корпуси працюватимуть, крім керування
  вентилятором (`--no-argon`).
- Під час першого старту потрібен інтернет: ставляться пакети і клонується репозиторій.
- Встановлення **повністю стирає SSD**.
